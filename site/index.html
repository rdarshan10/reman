For AI agents

Your agents stop guessing commands.

Claude Code, Codex and Cursor ask reman before they write a command, and reuse the ones that already work on your machine. reman never makes one up: every answer really ran.

  • Connected at install: ten MCP tools, and a local HTTP endpoint.
  • Stuck in a retry loop? The agent is told, in its own context, to change something first.
  • No history until you approve a folder. An agent can't approve one for itself.
