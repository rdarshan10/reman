Why reman

History remembers text.
reman remembers intent.

You know you've done it before, but not the flags, the folder, or which of five variants worked. Up-arrow can't help with that. reman can.

01

Type what you want, not what you remember. "run migrations" finds alembic upgrade head, even when the words don't match.

  • This folder first, then everywhere, so a search never dead-ends
  • Press ↑ in any shell and start typing

02

Proof of what worked

Every command carries its track record, so you reuse the one that works, not the one that happens to be newest.

  • Worked every time, failed every time, or the success rate
  • Where it ran, how often, and when you last ran it
  • A command that only ever failed never leads a list

03

Fixes, learned from you

When a command fails, reman shows what you ran next the last time, and it worked. Alt+F puts the fix on your prompt.

  • Proven fixes first, then the closest command that worked
  • Open the finder right after a failure and the fix is waiting
  • Real exit codes in every shell, even under a Python venv
powershell
PS ~/projects/api> gti status
gti : The term 'gti' is not recognized as the name of a cmdlet
reman: did you mean → git status (Alt+F inserts)
PS ~/projects/api> git status ← Alt+F

  • Predictions: an empty search shows what you usually run next
  • Skip ahead any time, or insert the whole flow as one line

For AI agents

Your agents stop guessing commands.

Claude Code, Codex and Cursor usually write commands from scratch. With reman they reuse the ones that already work on your machine, with the track record to prove it.

  • Each agent sees only the project it's working in, unless you share more.
  • Secrets are redacted, and reman never generates a command: every result really ran.
